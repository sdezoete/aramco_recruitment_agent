# Structured Interview Guide

(Sample reference document with fictitious content, for development.)

## Principles
- Ask every candidate for the same role the same core questions.
- Score each answer against the competency anchors before discussing it with other interviewers.
- Record evidence, not impressions.

## Core competencies
1. Technical depth: can the candidate explain a past solution and its trade-offs?
2. Problem solving: how do they structure an unfamiliar problem?
3. Collaboration: an example of resolving a disagreement with a stakeholder.
4. Ownership: an example of seeing a difficult deliverable through.

## Scoring anchors
- 1: no relevant evidence
- 3: relevant evidence with some gaps
- 5: strong, specific evidence with measurable outcomes
